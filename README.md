# 夜游神 · 山河漫游 | NIGHT ROAMER

> 白天归生活，夜里归自己。三千山河，随便逛，不赶时间。

一个纯前端的 3D 中国山河漫游网站。无需后端、无需数据库，打开浏览器即可夜游全国 34 省级行政区的代表性景点。所有数据仅存储在你自己的浏览器 localStorage 中。

## 在线体验

**https://2421755157.github.io/xiaodong-yyds/**

手机和电脑均可访问。电脑端使用 WASD + 鼠标操控，手机端使用虚拟摇杆 + 滑动环视。

## 功能一览

### 真实景点资料
- **1892 个景点**中 **1710 个**配有**真实景点简介**（百科摘要 + 维基词条首段，转简体并清洗注音），其余冷门景点回退到内置文案
- 抓取走**结构化接口**而不是解析网页：百度百科 `openapi/BaikeLemmaCardApi` 取
  `title/key/abstract`，360 图搜 JSON 接口取实景照片。两者都是 JSON，
  页面改版、CSS 混淆都影响不到，也不需要浏览器指纹
- 冷门景点的中文名常与词条名不一致（「长城·八达岭」→「八达岭长城」、
  「七宝老街」→「七宝古镇」、「应县木塔」→「佛宫寺释迦塔」），
  管线会按「拆分·后半 / 城市+名称 / 去通用后缀」生成候选串逐个试，
  命中率 1718/1836（93.6%）
- 同名歧义有专门校验：「鸽子窝」在百科里是禾本科高粱属种质、
  「客天下」是宋祖英唱的那首歌——摘要命中「种质/学名/变种」或开头在定义单曲，
  且没有「位于/景区/公园/遗址」等景点信号时判否，宁缺勿错
- **34 个省级行政区 + 354 个城市**同样接入真实简介（覆盖 **380/388**）
- 每条简介下方标注**资料来源**并给出词条外链，可自行核查
- **1836 个景点全部有主图**，其中 **1801 张已下载到仓库本地**（`img/baike/`，
  按景点名 md5 命名、统一压到 800px / JPEG 80，共约 124MB），
  同源托管，不受防盗链与 Wikimedia 域名不可达的影响
- **1666 个景点**有**多图图组**（主图 + 2 张补充实景），补充图取自图搜结果，
  在详情页打开时才懒加载

### 全国页 · 省市封面
- **34 个省级行政区**的卡片封面换成该地最有辨识度的**地标实景**（故宫、外滩、天津之眼、
  洪崖洞、平遥古城、黄山云海、布达拉宫…），不再是一层渐变底 + 一个单字
- **354 个城市**卡片复用该市首个景点照片，零额外体积
- 封面由 `tools/build_covers.py` 生成：先手工指定每个省的地标，再图搜，
  并要求**图片标题里含该地名**（否则「天津之眼」会搜出简笔画、「湖北」会搜出绘画素材），
  同时丢掉竖图与地图/门票类，最后裁成横构图压到 1000px
- 图片缺失或加载失败自动退回原来的渐变底 + 单字，不会出现破图

### 景点详情页
- 图集**灯箱**查看：点击放大，← → 切换、Esc 关闭
- **同城别处**推荐：同类型景点优先，点击直接切换
- 长简介自动三行截断 + 展开/收起
- 图片骨架屏微光加载，失败自动降级为城市配色

### 历史沿革 · 地标来历
- 详情页新增独立区块：**来历 · 地标故事**（遗址/寺庙/现代地标）或 **历史沿革**
- 内容取自维基词条正文，含建造年代、布局沿革、历史事件、名人轶事
  （如中山陵的建造时间线与设计者、黄山得名的传说、岳阳楼从"阅军楼"到"岳阳楼"的演变）
- **1729 个景点**有长介绍（平均 473 字），超过 180 字自动折叠 + 展开全文
- 有真实长文时，模板化的「详细解说」自动让位给史料（避免同一段通用文案出现两遍）
- 按首字哈希分成 8 个分片，打开景点时只加载对应那一片（约 100KB），首屏不受影响

### 实景全景（线上逛景点）
- 详情页新增 **🖐 360° 全景 / 宽幅全景** 按钮（仅对有真实全景资源的景点显示）
- 两种模式：
  - **sphere**：等距柱状（宽高比 ≈ 2:1）→ Three.js 球面贴图，站在球心 360° 环视，滚轮变焦
  - **wide**：宽幅拼接（宽高比 > 2.4）→ 平面贴图，横向拖拽环视，滚轮变焦
- 支持鼠标与手机触摸拖动、← → 方向键、ESC 关闭；纹理加载失败自动降级为平面照片
- 全景图片全部来自 Wikimedia Commons（长城、丽江古城、桂林、张家界、网师园、颐和园、故宫…）

### 位置小地图（已启用，无需额外申请）
- 详情页展示**带标记的真实地图**，一眼看出景点在城里的方位
- 三个视野档位：**街区**（看清门牌）→ **城区**（看清在哪一片）→ **全域**（看清离市中心多远）
- 「在百度地图打开 ↗」按钮跳转到百度地图的可交互地图页（带标题与自动标注）
- 底图来源：百度 `staticimage/v2` 静态图接口，输出 1024×768 高清
- 踩过的坑（已写进 `tools/probe_staticmap_params.py`）：
  - 官方参数表**没有 `maptype`** → 传卫星图参数会被静默忽略，仍返回路网图
    （瓦片服务 `maponline*.bdimg.com/tile/` 现已 404，静态图接口做不出卫星图）
  - `markers` 一旦带样式后缀（`|color:red`）整图会退化成 1×1 像素 → 只能传纯坐标
  - `scale=2` 时 width/height 上限只有 512 且 zoom 会自动 +1；
    改用 `scaler=2` 可放到 1024（输出 2048px）且 zoom 不变

### 实景街景（需在控制台申请服务）
- 详情页会多出一个「🛣 实景街景」按钮，点开就是该景点周边的**真实街景全景**
- **坐标库已备好**：773 个景点的经纬度（取自维基百科词条坐标 + Wikidata P625，
  WGS84），无需任何密钥
- ⚠ **AK 存在 ≠ 接口可用**：百度控制台的服务要逐个申请，未开通的接口一律返回
  `240 APP 服务被禁用`。所以按钮显隐由**构建期实测**出的服务能力决定
  （`js/config.js` 里的 `BAIDU_CAPS`），不会出现"点了必炸"的按钮
- 开通方式：
  - 百度：`https://lbsyun.baidu.com/` → 应用管理 → **服务管理** → 勾选开通
    - 「全景静态图」→ 详情页实景街景（`panorama/v2` + `fov=360`，服务端直接返回
      等距柱状图，可做 360° 环视；个人认证一般 10 万次/天免费额度）
    - 「地点检索」→ 采集 poiid（`tools/fetch_poiid.py`），
      poiid 指向景点正门，比只传经纬准确得多
  - 高德：`https://console.amap.com/dev/key/app` → Web 服务 Key
    → `restapi.amap.com/v3/streetview` 返回单视角街景图
- 开通后重跑一次探测即可自动更新能力状态：
  ```bash
  python tools/probe_baidu_api.py --write
  ```
- 百度接口未返回 CORS 头，因此做了**双通道降级**：优先球面贴图（真 360° 环视），
  跨域受限则自动转为等距柱状图的横向拖拽环视（无需 WebGL）；
  该位置没有覆盖街景时显示明确提示，而不是一张破图

### 3D 场景里的实景看板
- 进入 3D 漫游时，出生点旁会立起一块**该景点的真实照片看板**（始终朝向玩家）
- 让程序化生成的场景里也带着真实样貌，不再是"想象中的风景"

### 自选封面
- 详情页可直接上传**本机照片**作为景点封面（自动压缩到 1400px/JPEG，仅存浏览器本地，不上传服务器）
- 自定义封面同时作用于列表卡片与详情页大图，可一键「恢复默认」
- 用于补齐 Wikimedia 上确实没有照片的冷门景点——这是比自动抓取更可靠的来源

### 搜索
- **输入即搜**（防抖 220ms），无需点按钮
- 结果支持按**类型**（景点/城市/省份）与**省份**筛选
- 命中关键词高亮，名称命中的结果优先
- 快捷键：`/` 聚焦搜索框、`Esc` 清空或关闭结果

### 图片容错
- 三级换源：缩略图 → **原图域（不同域名，主域超时仍可加载）** → 官方文件路径接口
- 封面/图集/卡片统一走容错通道，失败自动降级为城市配色

### 网址即位置
- 地址栏同步当前层级：`#/江苏` → 城市列表，`#/江苏/无锡` → 景点列表
- 链接可直接分享，刷新不丢位置；下次进入自动回到上次浏览的省市

## 首屏加载策略

首屏只渲染省份网格（渐变封面 + 真实简介），**不碰 3D 引擎、不碰景点图库**。
这两块曾是最重的静态依赖，现已全部移出关键路径：

| 资源 | 体积（gzip） | 何时加载 |
|------|-------------|---------|
| `three.module.js` + 后期处理 addons | 264 KB | 点「进入 3D 漫游」时；首屏空闲预热 |
| `spot-images-db.js`（1892 处景点封面） | 68 KB | 进入「景点列表」层时；首屏空闲预热 |
| `region-desc-db.js`（380 条省市简介） | 31 KB | 首屏（省卡直接要显示） |
| `app.js` + 省市数据 + 其余首屏模块 | 92 KB | 首屏 |
| `scenes-meta.js`（场景映射/时辰/种子） | 1.7 KB | 首屏（零依赖纯数据） |

**首屏脚本合计 124 KB（gzip）**，改动前约 486 KB，降幅 **74%**。

三个关键设计：

- **纯数据与引擎分离**：`scenes.js` 里混着 `PRO_SCENES`（4 条映射）和 1800 行场景生成代码，
  而前者是首屏就要用的。拆出零依赖的 `scenes-meta.js` 后，首屏不必为 4 行映射付 257 KB。
- **按需 + 空闲预热**：用 `requestIdleCallback` 在首屏渲染完后偷偷下好，
  用户真点进去时通常已就绪，既不占关键路径也不会干等。
- **加载失败可重试**：three 走 CDN，断网/被拦时 `ensureRenderer` 会清空缓存允许重试，
  并给出「3D 引擎加载失败」的明确提示，而不是白屏。

## 质量保障

```bash
python tools/check_integrity.py   # 静态检查：DOM id / import 路径 / 导出名
node tools/unit_test.mjs          # 单元测试：纯函数 34 项（无需浏览器）
node tools/e2e_check.mjs          # 端到端：真实浏览器跑 42 项交互断言
npx eslint js/ tools/ -c eslint.config.mjs   # 代码风格与潜在缺陷
```

**单元测试**（`tools/unit_test.mjs`）覆盖 E2E 测不到的边界：
懒加载库的失败降级与去重语义、静态图/街景的参数校验（NaN、越界、zoom 夹取）、
XSS 转义、图片去重，以及**按需加载后的「未就绪」状态**——
图库没加载完时统计必须返回 0 而不是抛错或显示假数据。
**它当场抓出过两个真 bug**：`opts.zoom || 15` 让 `zoom=0` 绕过下限检查（0 是 falsy）、
以及 `getSpotImages` 的去重遗漏。
其中 `scenes-meta: spotSeed` 用例把哈希值写死（故宫 = 827142）：
这个种子决定每个景点的 3D 场景布局，算法一改所有场景外观都会变。

**E2E** 用 Chrome/Edge 的调试端口直连（无需第三方依赖），覆盖首页渲染、三级导航、
详情弹窗、图集、相关推荐、来源标注、历史沿革、模板解说让位、lazyDB 语义、
位置小地图、视野切换、街景按钮能力校验、灯箱、搜索（含命中简介正文）、3D 场景、
控制台零报错。

其中 4 条专门守首屏加载策略，防止以后又被随手 `import` 回去：
静态依赖扫描（`app.js` 里不许出现 `three` / `scenes.js` / `roam.js` / `panorama.js`）、
按需模块的下载时序（必须晚于 `app.js` 执行完成）、以及进入对应层级后确实已加载。
**详情弹窗曾因一处漏掉的 import 长期打不开，就是靠这个测试抓出来的。**

## 数据管线（可复现）

站内所有真实资料（景点照片 / 景点简介 / 省市简介）均由 `tools/` 下的脚本抓取生成，
原始缓存在 `data/`，可随时重跑、断点续跑、增量更新：

```bash
node tools/build-spot-index.mjs            # 重建景点/省市索引
python tools/fetch_baike_api.py --all      # ★ 主通道：百科 openapi 摘要 + 图搜照片（无浏览器）
python tools/download_baike_img.py         # 把图片下载到 img/baike/ 并压到 800px（同源托管）
python tools/merge_baike.py                # 并入 img_db / desc_db / long_db
python tools/build_covers.py               # 生成省市卡片封面 → js/cover-db.js + img/cover/
python tools/fetch_descriptions.py          # 补真实简介（景点 + 省市）
python tools/fetch_images.py --mode gallery --limit 500   # 补景点照片（Wikimedia，备用）
python tools/export_db.py                   # 导出前端静态库
python tools/fetch_long_desc.py              # 导出历史沿革长介绍（分 8 片）
python tools/fetch_panorama.py               # 抓真实全景图（球面/宽幅）
python tools/fetch_coords.py                 # 抓景点坐标（维基 + Wikidata，无需密钥）
python tools/resolve_disambig.py --both      # 消歧义词条重定向到正确条目
python tools/fetch_poiid.py                  # 采集 poiid（需百度「地点检索」权限）
python tools/probe_baidu_api.py --write      # 探测百度各服务开通状态 → config.js
python tools/probe_staticmap_params.py       # 静态图参数边界备忘（防踩坑）
python tools/clean_long_disambig.py          # 清洗长介绍里的消歧义残留
node   tools/baidu_retry.mjs                 # 百科 HTML 通道低频重试（风控解封后自动补抓）
node   tools/fetch_baike.mjs --all           # 百科 HTML 通道（需无头浏览器，被风控时用不了）
```

详细用法与踩坑记录见 [`tools/README.md`](tools/README.md)。

│   ├── region-desc-db.js   # 省市真实简介库（378 条）
│   ├── coords-db.js        # 景点坐标库（773 条，WGS84）

├── tools/              # 数据抓取管线（Python + Node，详见 tools/README.md）
├── data/               # 抓取原始缓存（断点续跑用）
